# Nova Landing Page

A responsive SaaS/productivity landing page built with plain HTML, CSS, and JavaScript.

## Run the project
1. Extract the ZIP file.
2. Open the `nova_landing_page` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Project features
- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- Product dashboard mockup made with HTML and CSS
- Feature cards, workflow section, testimonials, and pricing section
- Email input validation and demo success message
- Smooth in-page navigation and reduced-motion support

## Files
- `index.html` contains the page structure and content.
- `style.css` contains styling, layout, and responsive breakpoints.
- `script.js` controls the mobile menu and demo sign-up form.

## Notes
The sign-up form is a front-end demo only. It does not send or store email addresses. Profile photos and fonts load from external services, so an internet connection is needed for those assets.
